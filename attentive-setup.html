Attentive API Key — Setup Guide

For the PharmaGrade Core plugin SMS integration (pharmagradepeptides.is) · September 26, 2026

Step 1 — Create the API key in your Attentive account

  1. 1 Log in to your Attentive dashboard.
  2. 2 Open this direct link: ui.attentivemobile.com/integrations/custom-app/management — Attentive's official documentation states: “To generate a unique API key, you must create an app in the Attentive platform.”
  3. 3 Create a new custom app (name it for example PharmaGrade Website).
  4. 4 Enable the subscriptions:write scope — the documented scope for “Read and write permissions to the Subscribers API,” which covers the subscribe endpoint the website form uses.
  5. 5 The platform shows the unique API key once — copy it immediately and store it safely (Attentive treats it like a password: anyone holding it can message your customers).
If you cannot access that page, some accounts need it enabled first — Attentive's documentation says to email api-tokens@attentivemobile.com for access.

Step 2 — Connect the key to the website

  1. 1 WordPress admin → Settings → PharmaGrade Access → API & SSO Credentials.
  2. 2 Paste the key into the Attentive API Token field.
  3. 3 Click Test connection — you should see the green “✓ Token accepted” message (it checks authentication without creating any subscriber).
  4. 4 Click Save changes. From now on, every signup where the SMS box is ticked is pushed to Attentive automatically.

How the integration works (technical reference)

  • Endpoint: POST https://api.attentivemobile.com/v2/subscriptions (the Add Subscriptions endpoint per docs.attentive.com/reference/addsubscriptions).
  • Authentication header: Authorization: Bearer <your API key>.
  • Phone numbers are normalized to E.164 automatically — (555) 000-1234 becomes +15550001234.
  • A successful submission returns 202 Accepted; the subscription is then created asynchronously on Attentive's side.
  • The SMS checkbox on the signup form is the explicit marketing consent captured with each submission.

Troubleshooting

SymptomMeaning / Fix
Test connection: red “Rejected — token is not valid”The key was copied incompletely or revoked — generate a new one in the custom app page.
Test passes but live signups failYour Attentive account may require a Sign-up Unit ID. Find it in the Attentive platform → Sign-up Units tab → ID column, share it, and it will be added to the integration (one-line change).
Test connection: red “Unexpected response”Network or Attentive outage — retry in a few minutes.
